# Updates from the internet

A native carousel below trailers, with official-source videos from a rolling **14 days**. It shares the trailer key, repository, cache, throttling and approximate six-hour refresh job; no extra backend, API key or embedded player is required.

Filters: **All updates · AI & models · Startups · Robotics & mobility · Space · Devices & tools**.

Sources include OpenAI, Google/Google DeepMind, Anthropic/Claude, Y Combinator, Tesla, Figure, Boston Dynamics, NVIDIA, Apple, Microsoft, SpaceX and Unitree. Channel IDs and ownership-reference URLs live in `app/src/main/assets/trailer-sources.json`. Additional verified sources can be added there; new matching uploads on existing sources need no app update.

The Startups policy intentionally includes recent official YC founder/design/AI discussions and launch-video advice. Other publishers require launch/demo/new-product evidence and exclude rumors, tutorials, reactions, earnings, customer stories and recurring episodes. This is curated channel discovery, not exhaustive internet search or discovery of every YC company's independent channel.

Up to 30 newest qualifying topics appear. Conservative identity/version matching groups repeated coverage, regional copies and title variants; distinct model/product versions remain separate. It cannot perfectly infer the topic of every future upload. Dates are source publication timestamps. If a filter has no qualifying upload, Cinema shows that state honestly.

From a trailer press Down to Refresh, then Down again to enter this section. Left/Right browses; OK opens the exact YouTube video. Up/Back restores the previous trailer. From a tech card, Down → Right → Right → OK opens the filter. Selection/scroll is retained per filter across YouTube return and process recreation.

Expiry and the 72-hour NEW marker use scheduled callbacks, not a rendering loop. Offline items remain only while eligible within the 14-day window. See [trailer setup and storage](TRAILERS.md) and [testing](../docs/TESTING.md).
